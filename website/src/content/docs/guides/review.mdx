1. Open the doc in a pane or in the preview. The agent can open it for you with `pane_add`.
2. Select text and press `C`, or click the comment button next to the selection. Write your comment.
3. Add more comments. Each one keeps the quoted text.
4. Press `Ctrl+Enter` to send all the comments to pi as one message, with the quoted text and the file.

When pi is busy, the message waits until the current turn ends.

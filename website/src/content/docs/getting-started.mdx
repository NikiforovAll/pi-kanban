pi-kanban is an agent development environment for the pi coding agent. It runs pi sessions in a browser terminal and shows each session's todos, subagents, and linked docs next to it. Its skills and its `ask` tool let the agent show you cards, ask you questions, and hand tasks to other sessions.

## Requirements

- **Node.js 20 or later.**
- **The pi coding agent.** pi-kanban reads the session files pi writes to `~/.pi/agent/sessions`.

## Install

```sh
pi install npm:pi-kanban
npm install -g pi-kanban
```

The first command gives pi the `/kanban` command, the `ask` tool, and the skills that drive the board. The second installs the `pi-kanban` command, which runs the board.

## Start the board

Run this in a shell:

```sh
pi-kanban
```

The board listens on `127.0.0.1:3460` and prints its URL with the access token. Open that URL, then click **+ New** to start pi in the board terminal.

When pi runs in another terminal, run this inside pi to open the board with its token:

```text
/kanban open
```

Sessions, todos, and subagents appear on the board as pi works. See the [user guide](../guides/user-guide/) for a tour of the board, and the [CLI reference](../reference/cli/) for every command and flag.

:::note[Security]
The board listens on loopback only. The terminal needs a token that the board keeps in the URL fragment (`#t=...`), so the browser never sends it to a server. Do not share that URL.
:::

## Fill the board

pi-kanban shows data that other pi packages write. Install them next to it:

```sh
pi install npm:pi-subagents
pi install npm:@juicesharp/rpiv-todo
```

- [`pi-subagents`](https://www.npmjs.com/package/pi-subagents) starts named subagent sessions. The board shows them under each parent session.
- [`@juicesharp/rpiv-todo`](https://www.npmjs.com/package/@juicesharp/rpiv-todo) tracks todos. The board shows them as columns.
- [`@juicesharp/rpiv-ask-user-question`](https://www.npmjs.com/package/@juicesharp/rpiv-ask-user-question) asks you questions in the pi terminal. The board marks the session as waiting until you answer.
